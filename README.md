# MD卡图Mod工具

《游戏王：大师决斗》（Yu-Gi-Oh! Master Duel）的本地 Mod 管理工具：整包替换、卡图浏览换图、超框卡图制作、自动备份与一键还原。

## 功能特性

- **Mod 整包替换**：递归扫描 mod 包，多版本（ver1/ver2）同名文件逐个选择混装；兼容无 hex 目录层级的扁平打包；替换后自动同步同卡镜像 Bundle
- **卡图浏览换图**：按游戏内官方中文卡名搜索，支持「全部 / 仅超框 / 仅普通」筛选；单图替换前可裁剪（比例自动锁定，防止拉伸变形）
- **超框卡图制作**：分图层合成 704×1024 超框卡面 —— 插图层（本地图片 / 游戏原图 / 空白底色）、主体抠图跨出框线、卡框层（游戏原生 16 种卡框或本地图片）、边框叠加（`tools/border` 预置边框）、效果框透明度、超框层遮罩；写入时自动登记游戏超框表并联动同名同图卡，支持单卡工程的导出/导入（zip）
- **Bundle 内容预览**：双击/右键查看任意游戏资源包内的贴图/模型/音效清单，贴图可导出 PNG；还原管理页可切换「游戏当前 / 原版备份」对比
- **自动备份与还原**：原版文件替换前自动备份（只备份一次，永不覆盖），还原管理页一键恢复；超框还原会同步撤销登记与编辑记录
- **安全防护**：替换/还原前检测游戏进程；建索引与整包替换互斥防并发冲突；文件被系统占用时自动重试

## 系统要求

- Windows 10/11
- 已安装 Steam 版《游戏王：大师决斗》

## 下载

右侧 [Releases](../../releases) 页面下载 `MD卡图Mod工具.exe`，免安装，解压即用。

> 替换、还原、超框写入都需要**完全退出游戏**后再操作。

## 快速上手

1. 首次打开自动检测游戏目录（检测失败可手动选择游戏安装文件夹）
2. 打开「卡图浏览换图」页 → 点击「建立/更新卡图索引」（约几分钟，**仅需一次**，游戏更新后重建即可）
3. 打开「Mod 整包替换」页 → 「浏览...」选择 mod 包目录 → 「扫描预览」→「执行替换」
4. 想制作超框卡：在卡图浏览页选中卡片 → 打开「超框卡图制作」→ 摆好图层 →「制作并写入游戏」
5. 需要恢复原版时：「还原管理」页勾选 → 一键还原

> 卡图索引用于镜像同步（同一卡图的其他格式 Bundle）。只做非卡图替换（cutin/模型/音效等）可以不建索引；但超框制作需要索引来判断文字/版式与同名同图卡。

## 素材与数据目录

| 目录 | 说明 | 是否随仓库分发 |
|---|---|---|
| `tools/border/` | 预置边框叠加图（自制渐变），超框卡框下拉直接读取 | 是 |
| `overframe/` | 运行时生成：编辑记录、素材副本、游戏卡框缓存、导入的工程素材 | 否 |
| `_MD卡图备份/` | 原版文件备份与 manifest（位于 exe 同目录） | 否 |
| `card_index.sqlite` | 卡图索引库，本机自动生成 | 否 |

卡框不随包分发：型号直接读取游戏 `masterduel_Data/data.unity3d` 内的原生卡框，界面里也可以临时选用本地图片。

## 从源码运行

```bash
pip install -r requirements.txt
python app.py
```

## 打包 exe

```bash
pip install pyinstaller
pyinstaller --clean --noconfirm "MD卡图Mod工具.spec"
```

## 项目结构

```
app.py              # Tkinter 界面（整包替换 / 卡图浏览换图 / 还原管理 三页签）
core.py             # 路径解析、游戏目录检测、备份/还原、Mod 包扫描
cards.py            # 卡图索引（sqlite）、卡图读取/替换、镜像同步
gamedata.py         # data.unity3d 解析（游戏内官方卡名提取）
overframe.py        # 超框卡图合成、写入游戏 Bundle、登记表维护
overframe_ui.py     # 超框卡图制作对话框
tools/border/       # 预置边框素材（随包）
MD卡图Mod工具.spec   # PyInstaller 打包配置
docs/               # 详细文档
```
