# MD卡图Mod工具

《游戏王：大师决斗》（Yu-Gi-Oh! Master Duel）的本地 Mod 管理工具：整包替换、卡图浏览换图、自动备份与一键还原。

## 功能特性

- **Mod 整包替换**：递归扫描 mod 包，多版本（ver1/ver2）同名文件逐个选择混装；兼容无 hex 目录层级的扁平打包
- **卡图浏览换图**：按游戏内官方中文卡名搜索，单图替换前可裁剪（比例自动锁定，防止拉伸变形）
- **Bundle 内容预览**：双击/右键查看任意游戏资源包内的贴图/模型/音效清单，贴图可导出 PNG
- **自动备份与还原**：原版文件替换前自动备份（只备份一次，永不覆盖），还原管理页一键恢复
- **安全防护**：替换/还原前检测游戏进程；建索引与整包替换互斥防并发冲突；文件被系统占用时自动重试

## 系统要求

- Windows 10/11
- 已安装 Steam 版《游戏王：大师决斗》

## 下载

右侧 [Releases](../../releases) 页面下载 `MD卡图Mod工具.exe`，免安装，解压即用。

## 快速上手

1. 首次打开自动检测游戏目录（检测失败可手动选择游戏安装文件夹）
2. 打开「卡图浏览换图」页 → 点击「建立/更新卡图索引」（约几分钟，**仅需一次**，游戏更新后重建即可）
3. 打开「Mod 整包替换」页 → 「浏览...」选择 mod 包目录 → 「扫描预览」→「执行替换」
4. 需要恢复原版时：「还原管理」页勾选 → 一键还原

> 卡图索引用于镜像同步（同一卡图的其他格式 Bundle）。只做非卡图替换（cutin/模型/音效等）可以不建索引。

## 从源码运行

```bash
pip install -r requirements.txt
python app.py
```

## 打包 exe

```bash
pip install pyinstaller
pyinstaller --clean --noconfirm "MD卡图Mod工具.spec"
```

## 项目结构

```
app.py            # Tkinter 界面（整包替换 / 卡图浏览换图 / 还原管理 三页签）
core.py           # 路径解析、游戏目录检测、备份/还原、Mod 包扫描
cards.py          # 卡图索引（sqlite）、卡图读取/替换、镜像同步
gamedata.py       # data.unity3d 解析（游戏内官方卡名提取）
MD卡图Mod工具.spec  # PyInstaller 打包配置
docs/             # 详细文档
```
