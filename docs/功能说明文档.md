# MD 卡图 Mod 工具 — 功能说明

## 1. 概述

本工具用于给《游戏王 Master Duel》（Steam 版）替换卡图：支持整包 Mod 文件覆盖、单张卡图自定义替换，并提供原版备份与一键还原能力。

| 项 | 说明 |
|---|---|
| 形态 | Windows 桌面软件（Tkinter 界面，三个功能页签） |
| 分发 | 单文件 exe，免安装 |
| 代码逻辑详解 | 见配套文档《代码逻辑说明.md》 |

### 游戏资源结构（理解本工具的前提）

游戏卡图存放在 Unity AssetBundle 文件中，分布在**两个根目录**：

```
游戏根目录\
  LocalData\<玩家ID>\0000\        ← local 根：按需下载的资源（绝大多数卡图）
    5d\5df9f7a4                   ← Bundle：2位hex目录 + 8位hex文件名
  masterduel_Data\StreamingAssets\AssetBundle\   ← stream 根：随安装包下发（老牌经典卡）
    <hex>\<hash>
```

工具内部用统一相对路径标识文件：`local/5d/5df9f7a4` 或 `stream/xx/yyyyyyyy`（旧版清单中的裸 `xx/hash` 一律按 local 处理）。

## 2. 功能页签说明

### 页签一：Mod 整包替换

将从 Nexus 等渠道下载的 Mod 包整个覆盖到游戏目录。

**操作流程：**

1. 选择 Mod 源目录（可以是压缩包解压后的任意层级，工具会递归扫描）
2. 点击「扫描预览」
3. 若发现**同名文件**（不同文件夹里有相同的 Bundle，如 ver1/ver2 双版本），弹出逐文件选择窗口（见 2.1.1）
4. 列表确认无误后点「执行替换」：原版文件自动备份 → 覆盖 → 自动同步镜像 Bundle（见 2.1.2）

> **索引未建立时**：点「执行替换」会先弹出建议——卡图的镜像同步依赖索引，未建索引替换卡图 mod 可能新旧图混杂（非卡图 mod 不受影响）；可选择去「卡图浏览换图」页先建索引（只需一次），也可直接继续替换

**扫描识别规则（只认游戏 Bundle，其余一律忽略）：**

- 文件名必须是 8 位十六进制；父目录是 2 位十六进制时直接使用，父目录不是（如素材包直接平铺 `ABC\12b8f44c`）时按文件名前两位自动推导目标子目录
- 预览图（jpg/png）、作者附带的 backup 目录等全部自动跳过，扫描摘要中显示忽略数量
- 扫描结果列表中**双击或右键**任意文件，可预览该 Bundle 内的资源对象（名称/类型/尺寸）、翻看贴图、导出 PNG

**支持的 Mod 包布局：**

| 布局 | 示例 | 处理 |
|---|---|---|
| 扁平 0000 结构 | `0000\5d\5df9f7a4` 或 `5d\5df9f7a4` | 直接识别 |
| 嵌套多变体 | `卡名\ver1\0000\5d\5df9f7a4` | 任意深度均可，`0000` 定位 |
| 混合多张子包 | 目录 A 一批卡 + 目录 B 一批卡（无冲突） | 全部安装 |

#### 2.1.1 同名文件逐选（多变体包）

当不同文件夹里出现**相同相对路径**的 Bundle（典型如 ver1/ver2 双版本包），扫描后弹出选择窗口：

- 每个同名文件一行，列出全部变体的单选按钮（显示来源文件夹名 + 文件大小）
- 顶部「一键全选」按钮可批量统一为某个版本
- 每个文件可独立选择 → 支持混装（A 卡用 ver1、B 卡用 ver2）
- 点「取消」放弃本次扫描

**版本标签的显示规则：**

| 路径 | 显示的标签 |
|---|---|
| `...\ver1\0000\5d\5df9f7a4` | `ver1`（取最后一个 `0000` 的父目录名） |
| `ver1\5d\5df9f7a4`（无 0000 层） | `ver1`（取 hex 目录之上的相对路径） |
| `5d\5df9f7a4`（源目录根直接平铺） | `（根目录）` |

若同一文件的多个变体标签撞名，自动回退为更完整的来源路径，仍撞名则追加 `#1`、`#2` 保证可区分。

预览列表中有「来源版本」列，执行前可核对每个文件最终选中的版本。

#### 2.1.2 镜像 Bundle 自动同步

同一张卡的卡图可能同时存在于多个 Bundle 中（local/stream 两个根 × common/tcg/ocg 三种版本 × RGBA32/DXT5 两种格式）。整包覆盖通常只带了其中一部分文件，**不同步会导致游戏显示未替换的旧图**。

整包替换执行后自动进行镜像同步：

1. 读取每个 Mod 文件，提取其中的卡号与图片
2. 通过卡图索引反查这些卡号对应的**全部其他 Bundle**
3. 把图片写入这些 Bundle（同样先备份）

完成后提示"额外同步了 N 个镜像 Bundle"。

### 页签二：卡图浏览换图

浏览游戏中全部已实装卡片的卡图，并用本地图片替换任意一张。

**卡图索引（首次使用需建立，约几分钟）：**

- 点击「建立/更新卡图索引」：扫描 local + stream 两个根的全部资源
- 只收录真正的卡图（路径含 `card/images/illust/` 且尺寸为 512×512 或 512×1024 的贴图）→ 彻底排除图标、3D 材质、卡框等同名数字贴图
- 同一流程还会从游戏本体提取官方卡名（见 2.2.1）
- **游戏更新后重新执行一次即可加入新卡**

**浏览与搜索：**

- 搜索支持卡号 / 中文名 / 英文名 / 日文名的子串匹配（不区分大小写）
- 语言切换：中文 / EN / 日本語（显示与搜索同步切换）
- 「仅显示已替换」筛选：勾选后只列出已被 Mod 改过的卡
- 分页加载：每页 300 张，支持翻页与跳页
- 选中卡片右侧显示卡图预览、卡号、资源位置（下载数据/基础资源）、尺寸

**单图替换：**

- 「选择本地图片替换此卡图」：选图后先弹出**裁剪窗口**——按目标卡图比例锁定（512×512 → 1:1，512×1024 → 1:2），可拖动选区、四角缩放、区外点击重新框选；也可选「不裁剪用原图」（原图直接拉伸至目标尺寸，比例不符会变形）或「取消」
- 确认后自动替换该卡的**全部**卡图资源（跨根、跨版本一次完成，无需再同步镜像）
- 图片自动处理为游戏可用格式：保持原贴图尺寸（含 512×1024 竖版图），压缩格式归一为 RGBA32
- 「导出当前卡图为 PNG」：把游戏内卡图存到本地

#### 2.2.1 官方卡名库

卡名**不使用第三方数据库**（其译名与游戏内显示不一致），而是重建索引时直接从游戏 `masterduel_Data\data.unity3d` 中提取：

- 提取游戏实装卡 ID 序列与各语言官方卡名（中/英/日等）
- 输出 `game_card_names.json`，卡名与游戏内显示**完全一致**
- 浏览列表只包含**游戏内已实装且有卡图**的卡，不含未实装的外部数据库条目

卡名加载优先级：`game_card_names.json`（官方）→ `card_names_full.json`（旧第三方完整库回退）→ `cards.json`（旧简表回退）。

### 页签三：还原管理

列出当前处于 Mod 状态的全部文件，支持排序与还原。

- 排序：路径 / 时间升降序 / 方式（整包、单图）/ 类型（覆盖、新增）/ 有无原版备份；点列标题也可排序，同列再点翻转升降序
- **双击或右键**任意记录可预览该 Bundle：「覆盖」类文件可在预览窗口顶部切换「游戏当前(mod)」与「原版备份」直接对比
- 「还原选中」：把勾选文件还原为原版备份
- 「全部还原」：所有文件还原；标记为「新增」的文件（游戏中原本不存在）直接删除
- 还原后自动清理空的备份子目录

## 3. 安全机制

### 3.1 备份策略（只备份一次）

任何替换操作前，原版文件先复制到 `工具所在目录\_MD卡图备份\backup\`（exe 旁边），目录结构镜像游戏的相对路径。

**只在首次替换该文件时备份**，已有备份则跳过——保证备份永远是原版，不会把 Mod 文件误存为备份。

替换游戏中原本不存在的文件时记为「新增」，还原时直接删除。

### 3.2 Manifest 清单

`工具所在目录\_MD卡图备份\manifest.json` 记录每次替换的相对路径、时间、来源（整包/单图）、是否新增，还原管理页的数据即来源于此。

### 3.3 游戏运行检测

执行替换/还原前自动检查游戏进程，运行中则拒绝操作并提示关闭游戏——避免游戏运行中写入资源文件导致崩溃。

### 3.4 界面不卡死

索引扫描、整包替换、镜像同步、单图替换等耗时操作全部在后台执行，带进度条显示，界面可正常操作。

### 3.5 操作互斥（防并发冲突）

「建立卡图索引」与「整包替换」不能同时进行：一方运行时另一方的按钮自动禁用，强行点击会弹出等待提示。索引进度写入与替换的镜像同步共用同一索引数据库，互斥可避免数据库锁冲突导致的失败。

### 3.6 还原的文件占用容错

Windows 上刚读写的文件可能被杀毒软件/搜索索引短暂锁定（删除时报 WinError 32）。还原采用**两阶段**执行：先把全部原版拷回游戏，再统一删除备份（写删分离，降低撞锁概率）；删除被占用时自动退避重试约 10 秒。仍失败时该文件记录**保留在清单中**（界面可见），结果弹窗明确列出失败项——再次执行还原即是重试，不会出现"有残留但界面看不见"的盲区。

另外，预览窗口采用内存加载方式解析 Bundle（读完即释放文件句柄），开着预览窗口与还原/替换同时进行也不会互相锁定。

## 4. 数据文件说明

| 文件 | 位置 | 说明 |
|---|---|---|
| `config.json` | 工具目录 | 游戏根目录等配置 |
| `card_index.sqlite` | 工具目录 | 卡图索引库 |
| `game_card_names.json` | 工具目录 | 官方卡名（重建索引时生成） |
| `cards.json` / `card_names_full.json` | 工具目录 | 旧版卡名库，仅作回退 |
| `manifest.json` | `工具目录\_MD卡图备份\` | 替换清单 |
| `backup\` | `工具目录\_MD卡图备份\` | 原版文件备份（镜像相对路径） |

## 5. 使用注意事项

1. **首次使用前**：先在 Steam 中验证游戏文件完整性，确保备份到的是原版文件而非已有 Mod
2. **替换/还原前必须关闭游戏**（工具会强制检查）
3. 原版文件**只备份一次**，重复替换不会污染备份
4. 游戏更新后：点「建立/更新卡图索引」重新扫描，新卡自动加入（索引与官方卡名同步更新）
5. 卡图替换保持原尺寸与游戏可用格式，镜像 Bundle 自动同步，不会出现花屏或旧图残留
6. 各输入框（源目录/搜索/页码等）支持右键菜单：剪切/复制/粘贴/全选
